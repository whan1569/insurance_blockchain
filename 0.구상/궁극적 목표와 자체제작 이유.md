
## 🎯 **프로젝트 목표**

> **신뢰 가능한 사고 기록과 과실비율 데이터를 축적하여, 유사 사고에 대한 공정하고 자동화된 과실비율 판단 시스템을 구축**하는 것

### 구체적 목적:

* **사고 발생 시점부터 처리까지의 모든 정보를 투명하게 기록**
* **사고 유형별 과실비율 사례를 체계적으로 축적**
* **데이터가 쌓일수록, 유사한 사고에 대해 합리적인 과실비율을 자동 추천**
* **보험사, 사용자 모두에게 예측 가능하고 공정한 결과 제공**
* **장기적으로는 과실비율 기준의 산업 표준을 형성하는 데이터 플랫폼으로 발전**

---

## ⚙️ **왜 자체 블록체인이어야 하는가**

### ✅ 1. **맞춤형 데이터 구조 설계가 가능**

* 사고 정보, 참여자 정보, CCTV·사진 해시, 차량 움직임, 도로 상황 등 **도메인 특화 필드**를 블록체인에 최적화하여 설계할 수 있음
* 퍼블릭 체인은 고정된 트랜잭션 구조로 인해 세부 데이터 표현에 한계가 있음

---

### ✅ 2. **AI 학습을 위한 고품질 데이터 확보**

* 블록체인 기반 기록은 위변조 불가하므로, **AI 학습용 데이터로 신뢰성이 매우 높음**
* 데이터 포맷, 전처리 방식 등을 자체 체인에 맞춰 설계함으로써, AI 모델과 연동이 수월해짐

---

### ✅ 3. **수수료와 성능 제약 없이 운영 가능**

* 퍼블릭 체인은 트랜잭션 당 수수료 발생, 혼잡 시 속도 저하 등 문제 존재
* 자체 체인은 트랜잭션 비용 없이 대량의 사고 데이터를 안정적으로 처리 가능

---

### ✅ 4. **플랫폼을 통제하고 자산화할 수 있음**

* 퍼블릭 체인을 사용할 경우 핵심 데이터를 외부 네트워크에 의존
* 자체 체인은 **데이터, 네트워크, 규칙 모두 직접 관리**할 수 있어, **장기적으로 산업 플랫폼화 및 데이터 자산화**가 가능

---

### ✅ 5. **규제 대응과 보안 정책 커스터마이징 가능**

* 보험 및 개인정보와 관련된 법률은 국가마다 다름
* 자체 체인을 통해 **데이터 저장 위치, 접근 제어, 로그 추적 등**을 **법적 기준에 맞게 직접 설계 및 조정** 가능

---

| 당신의 목표          | 퍼블릭 체인 한계                | 자체 제작의 이점            |
| --------------- | ------------------------ | -------------------- |
| 유사 사고의 과실비율 판단  | 세부 사고 데이터를 구조화해 저장하기 어려움 | 특화된 데이터 구조를 설계 가능    |
| 데이터 축적 기반 AI 학습 | 트랜잭션당 비용 발생, 저장 제약 있음    | 대량 데이터 수집과 연동 최적화    |
| 플랫폼으로 확장        | 데이터 주권 없음, 확장성 낮음        | 완전한 통제권 + 수익모델화 가능   |
| 규제 대응           | 커스터마이징 어려움               | 보안정책과 규제에 유연하게 대응 가능 |

> **"신뢰 가능한 데이터 축적 → 학습 → 판단 → 공정성 확보"라는 데이터 기반 플랫폼 구축**이 핵심입니다.
