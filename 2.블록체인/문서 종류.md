## ✅ 문서 종류 분류표 (보험 사고 처리 관련, 저장 가능 항목)

| 구분        | 문서 종류                                                                        | 설명                           |
| --------- | ---------------------------------------------------------------------------- | ---------------------------- |
| 📄 공식 문서  | **사고 사실확인원** (`doc_police_report`)                                           | 경찰이 발급한 공식 사고 확인 문서          |
|           | **교통사고 조사보고서** (`doc_police_analysis`)                                       | 사고의 원인 및 결과 분석 보고서           |
|           | **보험 접수 확인서** (`doc_insurance_report`)                                       | 보험사에 사고가 접수되었음을 확인하는 문서      |
|           | **보험 조사보고서** (`doc_insurance_analysis`)                                      | 손해사정인이 작성한 사고 분석 및 책임 판단 문서  |
| 🏥 의료 문서  | **진단서** (`doc_medical_01`, ...)                                              | 병원에서 발급한 진단서                 |
|           | **치료비 청구서** (`doc_medical_bill_01`, ...)                                     | 병원에서 청구한 치료비 내역              |
|           | **입퇴원 확인서** (`doc_hospitalization_01`, ...)                                  | 치료 기간 및 입원 여부 증빙 문서          |
| 📝 당사자 문서 | **보험 청구서** (`doc_claim_01`, ...)                                             | 가입자가 보험금 지급을 요청하는 문서         |
|           | **진술서** (`doc_statement_claimant`, `doc_statement_respondent_01`)            | 사고에 대한 당사자의 주관적 설명           |
|           | **합의서** (`doc_agreement_01`, ...)                                            | 민사 합의 또는 중재 결과에 대한 문서        |
|           | **동의서** (`doc_consent_01`, ...)                                              | 특정 절차(예: 영상 제공)에 대한 당사자의 동의서 |
| 💼 기타 문서  | **차량 등록증** (`misc_vehicle_registration_claimant.pdf`)                        | 차량 소유자 증명                    |
|           | **운전면허증 사본** (`misc_license_claimant.pdf`, `misc_license_respondent_01.pdf`) | 사고 당사자의 신분 확인용               |
|           | **보험 가입 증명서** (`misc_policy_certificate.pdf`)                                | 유효한 보험 계약을 증명                |
|           | **세금계산서/영수증** (`misc_receipt_01.pdf`, `misc_receipt_02.pdf`)                 | 사고 처리와 관련된 비용 지출 내역          |
|           | **정비소 견적서** (`misc_repair_estimate_01.pdf`, `misc_repair_estimate_02.pdf`)   | 차량 수리 견적서                    |
