

# ✅ **세션 1: 블록체인 기반 인프라 구축**

### 🎯 목표: 시스템의 중심이 되는 프라이빗 블록체인과 노드 네트워크, 합의 구조 및 기본 트랜잭션 처리 구조 완성

---

## 🔹 1. P2P 네트워크 및 노드 구성

* libp2p 또는 WebSocket 기반의 P2P 네트워크 구축
* 참여 노드 / 검증 노드 / 관리자 노드 역할 구분 및 인증 시스템 도입
* 각 노드 상태 관리 (ping/heartbeat)

---

## 🔹 2. 블록 구조 및 트랜잭션 포맷 설계

* 블록 구조 (헤더, 트랜잭션 목록, 이전 해시, 타임스탬프 등)
* 트랜잭션 구조 (보낸 사람, 받는 사람, 서명, 데이터 등)
* 트랜잭션 유효성 검사 로직 (서명 확인 등)

---

## 🔹 3. PoA 기반 합의 알고리즘 구현

* 정해진 검증 노드만 블록 생성 가능하게 제한
* 블록 생성 주기 조정 (5\~10초 목표)
* 블록 검증 후 네트워크에 전파

---

## 🔹 4. 오프체인 저장소 연동 (기초)

* IPFS 연동 테스트
* 블록체인에는 데이터 해시만 저장, 원본은 IPFS에 저장
* 사고/계약 파일과의 연결 구조 설계

---

## 🔹 5. API 서버 (기초 트랜잭션 처리)

* 사용자/노드가 트랜잭션 전송하는 REST API 구축
* 노드 간 블록 전파 API
* 블록 조회/트랜잭션 조회 API

---

# ✅ 산출물

* P2P 네트워크 코드
* PoA 합의 구현
* 블록/트랜잭션 기본 구조
* 트랜잭션 API 서버
* 오프체인 연동 구조 설계

# ✅ **세션 2: AI 판단, 스마트 계약, 오프체인 처리 구현**

### 🎯 목표: 과실 판단 AI, 보험 계약 로직을 스마트 계약으로 자동화, 오프체인 데이터 처리 구축

---

## 🔹 1. AI 기반 사고 책임 판단 모듈

* 입력: 사고 정보 (문서, 이미지, 텍스트 등)
* 출력: 과실 비율 (예: A 70%, B 30%)
* Rule-based + ML 결합
* 모델 결과 REST API로 반환

---

## 🔹 2. 스마트 계약 시스템

* 사고 보고 → AI 판단 → 계약 실행 흐름 구축
* 조건부 자동 지급 로직 구현 (과실 비율, 보험 종류 등 기준)
* Solidity / Hyperledger 기반 계약 로직 구현

---

## 🔹 3. 오프체인 저장소 통합 및 구조 고도화

* 사고 기록, 판결서, 계약서 원본 저장
* 블록체인에는 해시만 저장
* 사용자 및 노드가 IPFS 접근 가능한 인터페이스 설계

---

## 🔹 4. 예외 사고 처리 (인간 검토)

* AI 판단 불가능한 사고 예외 처리 구조 설계
* 수동 검토자(보험사 직원)가 판단 후 입력
* 판단 결과도 블록에 기록

---

## 🔹 5. 역할 기반 사용자 인증

* 보험사, 피해자, 가해자, 검토자 등의 역할별 인증
* OAuth2.0 또는 JWT 기반 인증 구조 설계

---

# ✅ 산출물

* AI 모델 및 API 서버
* 스마트 계약 샘플 및 배포 자동화 스크립트
* IPFS 연동 구조 완성
* 예외 사고 수동 처리 플로우
* 사용자 권한 관리 시스템

---

* 정상 시나리오, 예외 시나리오 테스트 자동화
